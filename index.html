Open-source geographic globe

OpenAtlas Globe

A reusable 3D Earth extracted from the World Explorer in Malaysia Linguistics Lab. Drag to rotate. Use the flight control to approach an example region.

GitHub

Features

  • Cinematic Earth, atmosphere, clouds, and starfield
  • Pointer drag with inertia
  • Generic lat/lon markers from JSON
  • No backend, database, auth, or AI

Quick start

npm install
npm run dev

Data format

[
  {
    "id": "example",
    "name": "Example",
    "lat": 1.3,
    "lon": 103.8,
    "category": "city",
    "summary": "Any geographic point"
  }
]

The Malaysia language points in this demo are labeled example data only. OpenAtlas Globe is not a Malaysia-specific product.
