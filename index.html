Open-source 3D Earth

OpenAtlas Globe

An open-source, reusable 3D Earth for geographic exploration.

Interactive Three.js globe with realistic terrain and ocean textures, atmosphere, clouds, and a live day/night terminator. Markers are JSON-driven geographic points. No backend required.

GitHub

Day & Night

OpenAtlas Globe simulates sunlight across the Earth's surface, creating a continuously changing day/night boundary as the planet rotates.

Features

  • Interactive 3D Earth with realistic textures
  • Atmosphere, clouds, and starfield
  • Day/night lighting on the sphere
  • Optional automatic axial rotation
  • Generic lat/lon markers from JSON
  • No backend, database, auth, or AI

Quick start

npm install
npm run dev

Data format

[
  {
    "id": "example",
    "name": "Example",
    "lat": 1.3,
    "lon": 103.8,
    "category": "city",
    "summary": "Any geographic point"
  }
]

Default markers are generic cities for the marker system demo. Replace public/data/example-cities.json with your own dataset.
